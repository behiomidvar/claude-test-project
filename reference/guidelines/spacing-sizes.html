Size scale & the declared-height rule

Spacing is the gap between things; size is the dimension of a thing. Element dimensions come from --size-*, never a raw pixel and never from vertical padding.

The scale — 4px grid

Marks (8 / 12 / 16) are dots and indicators below the control floor. Controls start at 20. Steps are named by pixel value so the mapping is self-evident at the call site. If a design needs a value between steps, the step list is wrong — add the step, do not hardcode.

The rule

Fixed-shape components — declare the height

  • height comes from a --size-* step.
  • display:inline-flex + align-items:center centres the content.
  • Padding is horizontal only, from a spacing token.
  • Applies to every pill and capsule: Badge, Chip, VerificationBadge, AgeChip, DistanceChip, dots, count badges, tab items, segments.
  • Mark the declaration h: --size-24 declared in a comment, so a reviewer can see the height was chosen.

Never

  • No emergent heights. Padding + line-height must never be what produces a pill's height — that is how Badge shipped at 23px, a number nobody chose.
  • No min-height on a fixed shape; it invites growth and hides the real value.
  • No raw pixel dimension where a step exists.
  • Exempt but still tokenised: cards, message bubbles, list rows, textareas grow with content — their padding must still come from spacing tokens.
