A circular icon-only button — back arrows, overflow menus, voice-record, send. Always pass `label` for accessibility.

```jsx
<IconButton label="Send" variant="solid"><SendIcon/></IconButton>
<IconButton label="Back" variant="ghost"><ArrowIcon/></IconButton>
```

Variants: `ghost` (default), `solid`, `outline`. Sizes `sm | md | lg` — use `md`+ for touch targets.
