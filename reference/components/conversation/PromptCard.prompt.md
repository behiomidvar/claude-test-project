A profile prompt — the "words before faces" primitive. A question (display serif italic, cool) with the user's written answer. Profiles lead with these, not a selfie grid.

```jsx
<PromptCard
  question="What could you talk about all night?"
  answer="The films no one else has seen, and why my grandmother was right about everything." />
<PromptCard question="A small thing that made you happy this week?" />  {/* empty state */}
```

Props: `question`, `answer`, `label`.
