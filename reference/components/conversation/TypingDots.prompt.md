The three animated dots from the logo — Deltalk's signature device meaning "someone is about to speak." Use it in chat, loading states, section breaks, and build beats. This is a recurring brand motif, not just a chat feature.

```jsx
<TypingDots />                    {/* inherits currentColor */}
<TypingDots size="lg" brand />    {/* gradient hero version */}
<TypingDots color="var(--cool-violet)" />
```

Props: `size` (`sm|md|lg`), `brand`, `color`.
