Contents

Three reference sheets. Everything is drawn live from the Deltalk design system — the same token files and the same 49 React components that ship to production — so this kit cannot drift from the source of truth.

01FoundationsLogo lockups, the six brand accent stops and their nine-step ramps, the neutral ladder, every semantic role in light and dark, type scale, spacing, shape, elevation, motion, iconography. 02ComponentsAll 48 components in isolation, grouped by concern, each with its variants and states — default, selected, focus, pressed, disabled, error, loading, empty — rendered in light and dark side by side. 03ScreensSeven assembled screens — Onboarding, Discover, Chat, Likes, Profile, Settings, Paywall — at 390 × 844, each in both themes, built only from kit components and real Persian content.

How to read this kit

Documentation language is English; every piece of product content is Persian, because Persian is the source language of the product and not a translation. Numerals in UI content are Persian (۰–۹); the phone field and the OTP boxes are the two documented exceptions and use Latin digits.

Layout is RTL by default. Component code, token names and props stay English.

Every colour on these sheets is read from a semantic token at render time. Where a value is worth naming it is printed in monospace next to the specimen.

Scope & caveats

  • Type: IRANSansMobile (NoEn) is the only Persian family — UI, body and headings alike. Hanken Grotesk is used for Latin, JetBrains Mono for token names.
  • Icons: Lucide (MIT), 2px stroke, rounded caps. Swap for a brand-owned set if one exists.
  • Portrait imagery uses Unsplash placeholders — replace with licensed photography.
  • Paywall is drawn from the preserved --premium token family; it has no live component yet.
