01.1

Logo

Three lockups with fixed jobs. The icon is the hard ceiling and the type can never out-measure it: Compact is bottom-aligned only — the icon ink’s bottom edge sits on the wordmark’s ink baseline, and the icon (27u of ink in a 36u frame) rises above the 24u wordmark, Full is height-matched and centred against the wordmark + tagline block. Icon-to-type gap is a ratio of the mark — 0.25 horizontal, 0.20 vertical — never a hardcoded pixel value. Scale by height only, move the lockup as one unit; clear space on all four sides is the icon's height.

Compact is the only treatment in the persistent top bar, on every tab. Lockup height is fixed at 36px (1u = 1px: wordmark ink 24px, icon frame 36px, icon ink 27px); the container has no height requirement — size it to the bar and centre the glyph.

Full (wordmark + tagline + mark) is splash, onboarding and About only — never in repeating UI. It ships as one baked-fill asset per theme, so the tagline can never be substituted by a font.

Mark only is favicon scale, app icon and loading states, at 36px minimum — below that the 2026 icon’s typing dots drop under 2px. Lockup minimums: Compact horizontal 32px, Full horizontal 36px, Compact vertical 60px, Full vertical 78px.

01.2

Colour

Six brand accent stops sampled from the logo, each with a nine-step ramp interpolated in OKLCH lightness and gamut-mapped to sRGB. Step 500 is the stop itself. Ramps are theme-independent; everything a screen touches is a semantic role that flips per theme.

Accent stops

The one authoritative palette. Identical in both themes. Every named colour elsewhere in the brand documentation is an alias onto one of these six.

Tonal ramps

500 is the base value · 400–600 default flat usage · 700–900 tinted fills, hover and borders on light surfaces · 100–300 text and icons on top of those fills. Reach for a ramp step before color-mix() or a hand-lightened hex.

Neutral ladder

Deliberately not evenly interpolated: every neutral exists because it clears a measured bar — 3:1 for control outlines, 4.5:1 for text.

Gradients

One hero-gradient moment per screen. --gradient-brand is the branded-state fill — switch on-track, selected chips, progress, badges, match rings — and is theme-independent. Small text on gradient uses --gradient-brand-strong. Celebration is for match and onboarding hero moments only; never a UI state or a background.

--gradient-brandpink 500 → purple 500 · 135°
--gradient-brand-strongpink 600 → purple 600 · AA with white
--gradient-celebrationgold 500 → pink 500 · celebration only

01.4

Typography

IRANSansMobile (NoEn) is the only Persian family — UI, body and headings alike. Letter-spacing is zero everywhere (tracking breaks the Persian script) and line-heights are generous: 1.75 for body, up to 1.9 for long-form. Weights below 400 are avoided at small sizes for legibility.

01.5

Space, shape & elevation

A 4px base grid with a semantic layer on top. Reach for the role, not the number — a role can be re-tuned system-wide, a raw step cannot. Small pills and bubbles keep a documented 2px optical sub-grid.

Spacing roles

Raw ramp

Dimensions & targets

Radius roles

Five roles. The raw ramp carries no role notes on purpose — that is how components used to drift onto it. Bubbles compose from --radius-bubble 22 + --radius-bubble-tail 6 and mirror once, in tokens/radii.css, under [dir="rtl"].

Elevation

Soft shadows tinted toward the ink, never hard grey drops. Two coloured glows are reserved for a single hero action per screen.

Motion — the unfold, never the swipe

Nothing swipes away; things ease open and reveal. Press is a gentle shrink to --press-scale 0.97, hover a --hover-lift -2px card lift.

Iconography

Lucide (MIT) — rounded caps and joins, 2px stroke, humanist and open. No emoji, and no unicode glyphs used as icons. Directional icons (back, send) carry data-dir-icon and mirror in RTL; heart, camera, settings, profile and compass must not be tagged. The one non-Lucide device is the three dots, which comes straight from the logo and ships as TypingDots.
